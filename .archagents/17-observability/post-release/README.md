# Post-Release Reports

Relatórios pós-entrega (PRR-NNNN), gerados automaticamente pelo estágio **Observe**.

Cada PRR documenta: mudanças entregues, métricas observadas, incidentes, desvios de SLO e recomendações para o ciclo seguinte.

Fonte: pipeline `/ops-reflect` após cada entrega em produção.
