# Telemetry Plans

Planos de telemetria (TLP-NNNN) que definem quais eventos, métricas e logs instrumentar.

Criados no estágio **Design**, validados no estágio **Verify** e consumidos pelos dashboards e alertas.

Cada TLP deve declarar: escopo, eventos, métricas, retenção e requisitos de privacidade.
